# Privacy Policy

**Last updated:** 2026-02-13

This Privacy Policy explains what data this Discord bot Uphold collects and how it is used.

## Data we collect
- **Discord User ID**
- **Operational data** needed for the Bot to work (e.g. verification state and an expiration timestamp for verification codes)

We do **not** intentionally collect message content, emails, phone numbers, or any other personal data.

## Why we collect it
We use the Discord User ID only to:
- identify a user for the Bot’s features (e.g. verification/linking/cooldowns)
- prevent abuse and keep the Bot functioning correctly

## Where and how it’s stored
The Discord User ID is stored in a **MongoDB** database.

## Sharing
We do not sell, rent, or share your data with third parties, except if required by law.

## Retention
We keep your Discord User ID only as long as needed for the Bot to function.
You may request deletion at any time (see “Contact & deletion requests”).

## Security
We take reasonable measures to protect stored data, but no system can be guaranteed 100% secure.

## Contact & deletion requests
To request deletion of your data, contact: uphold.privacy@gmail.com
Include your Discord user ID or a link to your profile so we can locate your record.

## Changes
We may update this policy from time to time. The “Last updated” date will change when we do.
